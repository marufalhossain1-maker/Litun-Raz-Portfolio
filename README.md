# Litun Raz — Personal Website

A personal website showcasing Litun Raz, a student from Bogura, Bangladesh, with interests in football, nature, photography, videography, and drawing.

**Live Website:** https://litunraz.netlify.app/

## About

The website introduces Litun Raz through a personal profile, interests, photography, and contact links. Its design focuses on a modern dark aesthetic, subtle animations, and responsive layouts for mobile and desktop devices.

## Features

- Personal introduction and biography
- Football and nature-inspired personal identity
- Photography and image gallery
- Contact and social media links
- Responsive navigation for mobile and desktop
- Interactive animations and image viewing
- SEO metadata and social-sharing previews
- Web app manifest, robots.txt, and sitemap.xml

## Technologies

- HTML5
- CSS3
- JavaScript
- Netlify hosting

## Local Development

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` using the Live Server extension.
4. Edit the HTML, CSS, and JavaScript as needed.

## Deployment

The website is hosted on Netlify. Deploy the project folder or connect the repository to Netlify for automatic deployments.

## SEO Checklist

- Use a unique page title and meta description.
- Keep the canonical URL consistent with the live domain.
- Ensure the social preview image is publicly accessible.
- Verify `robots.txt` and `sitemap.xml` after deployment.
- Test the site on mobile devices.
- Submit the sitemap through Google Search Console.
